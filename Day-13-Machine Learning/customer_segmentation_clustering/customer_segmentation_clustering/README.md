# Customer Segmentation — Clustering Hands-on

Practical unsupervised-learning project using scikit-learn K-Means.

## Run
```bash
pip install -r requirements.txt
python src/generate_data.py
python src/clustering.py
```

Outputs: elbow curve, PCA cluster plot, cluster profiles, customer-level assignments, and interpretation notes.

## FDE focus
Cluster IDs are arbitrary. Profile and validate clusters before assigning business names or actions.
